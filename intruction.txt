# Сайт онлайн-записи к lash-мастеру: GitHub Pages + Supabase (всё бесплатно)

**Что получится:** нежный mobile-first сайт `https://USERNAME.github.io/lash-booking/` с записью в 3 тапа, админка `…/#/admin` (вход по пин-коду), уведомление мастеру в личку ВК при каждой новой записи.

**Ключевые инженерные решения (важно понять до кода):**
- **Роутинг через `#`**: GitHub Pages — тупой статический хостинг, он не умеет отдавать `index.html` на путь `/admin`. Поэтому админка живёт по адресу `/#/admin` — это работает всегда, без 404-хаков.
- **Пин-код = пароль единственного пользователя Supabase Auth.** Роль `authenticated` получает права админа через RLS. Регистрацию новых пользователей обязательно отключаем (шаг 2).
- **Запись — через RPC-функцию `book_slot`** (SECURITY DEFINER): слот бронируется атомарно, два клиента не займут одно окошко. Анонимный ключ публичный, поэтому вся защита — в RLS: таблицу `bookings` клиенты не читают вообще.
- Стек: Vite + React 19 + Tailwind v4 (плагин `@tailwindcss/vite`, без конфигов) [[20]] + `@supabase/supabase-js`. Уведомление — Edge Function + Database Webhook [[11]].

**`supabase/schema.sql`**

```sql
-- ============================================================
-- Lash Booking: схема Supabase. Выполнить в SQL Editor целиком.
-- ============================================================

-- 1) Услуги
create table if not exists public.services (
  id           uuid primary key default gen_random_uuid(),
  title        text not null check (char_length(title) between 1 and 100),
  price_rub    integer not null check (price_rub >= 0),
  duration_min integer not null check (duration_min > 0),
  sort         integer not null default 0,
  is_active    boolean not null default true,
  created_at   timestamptz not null default now()
);

-- 2) Окошки: строка = один час конкретного дня
create table if not exists public.slots (
  id         uuid primary key default gen_random_uuid(),
  day        date not null,
  hour       smallint not null check (hour between 0 and 23),
  status     text not null default 'free' check (status in ('free','booked')),
  created_at timestamptz not null default now(),
  unique (day, hour)
);
create index if not exists slots_day_idx on public.slots (day);

-- 3) Записи. Цена/название услуги «сфотографированы» в момент записи,
--    чтобы изменение прайса не ломало историю.
create table if not exists public.bookings (
  id            uuid primary key default gen_random_uuid(),
  slot_id       uuid not null references public.slots (id),
  service_id    uuid references public.services (id),
  client_name   text not null,
  phone         text not null,
  vk_link       text not null default '',
  service_title text not null,
  price_rub     integer not null,
  duration_min  integer not null,
  status        text not null default 'active' check (status in ('active','cancelled')),
  created_at    timestamptz not null default now()
);
create unique index if not exists one_active_booking_per_slot
  on public.bookings (slot_id) where status = 'active';

-- 4) RLS — вся безопасность здесь (anon-ключ публичный!)
alter table public.services enable row level security;
alter table public.slots    enable row level security;
alter table public.bookings enable row level security;

create policy services_read_active on public.services
  for select to anon using (is_active);
create policy services_admin_all on public.services
  for all to authenticated using (true) with check (true);

create policy slots_read_all on public.slots
  for select to anon using (true);          -- в слотах нет персональных данных
create policy slots_admin_all on public.slots
  for all to authenticated using (true) with check (true);

-- bookings: у anon НЕТ политик => ни чтения, ни записи напрямую.
create policy bookings_admin_all on public.bookings
  for all to authenticated using (true) with check (true);

-- 5) Атомарная запись клиента (вызывается без логина)
create or replace function public.book_slot(
  p_slot_id uuid, p_service_id uuid,
  p_name text, p_phone text, p_vk text default ''
) returns json
language plpgsql
security definer set search_path = public
as $$
declare
  v_slot    public.slots%rowtype;
  v_service public.services%rowtype;
  v_booking public.bookings%rowtype;
begin
  if char_length(trim(coalesce(p_name,''))) < 2 then
    raise exception 'NAME_REQUIRED';
  end if;
  if char_length(regexp_replace(coalesce(p_phone,''), '\D', '', 'g')) < 10 then
    raise exception 'PHONE_REQUIRED';
  end if;

  -- UPDATE ... WHERE status='free' — атомарная защита от двойной брони
  update public.slots set status = 'booked'
   where id = p_slot_id and status = 'free'
  returning * into v_slot;
  if not found then
    raise exception 'SLOT_TAKEN';
  end if;

  select * into v_service from public.services
   where id = p_service_id and is_active;
  if not found then
    update public.slots set status = 'free' where id = p_slot_id;
    raise exception 'SERVICE_NOT_FOUND';
  end if;

  insert into public.bookings
    (slot_id, service_id, client_name, phone, vk_link,
     service_title, price_rub, duration_min)
  values
    (v_slot.id, v_service.id, left(trim(p_name),100), left(trim(p_phone),30),
     left(trim(coalesce(p_vk,'')),200),
     v_service.title, v_service.price_rub, v_service.duration_min)
  returning * into v_booking;

  return json_build_object(
    'booking_id', v_booking.id,
    'day', v_slot.day, 'hour', v_slot.hour,
    'service_title', v_service.title,
    'price_rub', v_service.price_rub,
    'duration_min', v_service.duration_min,
    'client_name', v_booking.client_name,
    'phone', v_booking.phone
  );
end;
$$;

revoke execute on function public.book_slot(uuid,uuid,text,text,text) from public;
grant  execute on function public.book_slot(uuid,uuid,text,text,text) to anon, authenticated;

-- 6) Отмена записи мастером: запись → cancelled, окошко → free
create or replace function public.admin_cancel_booking(p_booking_id uuid)
returns void
language plpgsql
security definer set search_path = public
as $$
declare v_slot_id uuid;
begin
  update public.bookings set status = 'cancelled'
   where id = p_booking_id and status = 'active'
  returning slot_id into v_slot_id;
  if not found then
    raise exception 'BOOKING_NOT_FOUND';
  end if;
  update public.slots set status = 'free' where id = v_slot_id;
end;
$$;

revoke execute on function public.admin_cancel_booking(uuid) from public, anon;
grant  execute on function public.admin_cancel_booking(uuid) to authenticated;

-- 7) Демо-данные (отредактируйте под себя)
insert into public.services (title, price_rub, duration_min, sort) values
  ('Классическое наращивание', 2500, 120, 1),
  ('Объём 2D',                 3000, 150, 2),
  ('Объём 3D',                 3500, 180, 3),
  ('Снятие ресниц',             500,  30, 4);

insert into public.slots (day, hour)
select current_date + 1, h from generate_series(10, 19) as h
on conflict (day, hour) do nothing;
```

## Шаг 2. Пин-код мастера (Supabase Auth)

1. **Authentication → Sign In / Providers → Email**: провайдер включён, а **«Allow new users to sign up» — ВЫКЛЮЧИТЬ**. Это критично: любой зарегистрировавшийся получил бы роль `authenticated` и доступ к записям.
2. **Authentication → Users → Add user → Create new user**:
   - Email: `admin@lash.local` (должен совпадать с `ADMIN_EMAIL` в `src/config.js`);
   - Password: ваш пин-код, **минимум 6 цифр** (это и есть пин для входа);
   - Галочка **Auto Confirm User** — обязательно.
3. Сменить пин-код потом: тот же пользователь → Update password.

## Шаг 3. ВКонтакте: сообщество и ключ

1. В сообществе: **Управление → Сообщения → Сообщения сообщества: Включены**.
2. **Управление → Работа с API → Ключи доступа → Создать ключ** → право **«Сообщения сообщества»** (`messages`). Скопируйте токен — он показывается один раз.
3. **Мастер со своей личной страницы пишет сообществу любое сообщение** («привет»). Без этого VK вернёт ошибку `901 Can't send messages for users without permission` — сообщество не может написать первым [[6]].
4. Адресат сообщения — сам мастер. Задаётся либо коротким адресом страницы (`VK_DOMAIN`, например `alina_lash`), либо числовым id (`VK_PEER_ID`). Id удобно подсмотреть в URL диалога в сообщениях сообщества: `vk.com/gim…?sel=12345678` — `sel` и есть id.
5. Ссылка «написать мастеру» для клиентов: `https://vk.me/КОРОТКИЙ_АДРЕС` (страницы или сообщества) — её впишем в `config.js`.

## Шаг 4. Edge Function + Database Webhook (уведомления)

**`supabase/functions/notify-vk/index.ts`**

```ts
// Supabase Edge Function (Deno). Вызывается Database Webhook'ом
// при INSERT в public.bookings и шлёт мастеру сообщение от имени сообщества.
// Secrets: VK_TOKEN, VK_DOMAIN (или VK_PEER_ID), WEBHOOK_SECRET, ADMIN_URL (опц.)
import { createClient } from 'npm:@supabase/supabase-js@2'

const MONTHS = ['января','февраля','марта','апреля','мая','июня',
                'июля','августа','сентября','октября','ноября','декабря']

Deno.serve(async (req) => {
  // Простая защита: вебхук обязан прислать заголовок x-webhook-secret
  const secret = Deno.env.get('WEBHOOK_SECRET')
  if (secret && req.headers.get('x-webhook-secret') !== secret) {
    return new Response('forbidden', { status: 401 })
  }

  let payload: { type?: string; table?: string; record?: Record<string, unknown> }
  try { payload = await req.json() } catch { return new Response('bad json', { status: 400 }) }
  if (payload.type !== 'INSERT' || payload.table !== 'bookings' || !payload.record) {
    return Response.json({ skipped: true })
  }
  const b = payload.record as Record<string, string>

  // Дату/время слота достаём service-ключом (он живёт только здесь, не в браузере)
  const db = createClient(Deno.env.get('SUPABASE_URL')!, Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!)
  const { data: slot } = await db.from('slots').select('day,hour').eq('id', b.slot_id).single()

  let when = 'дата уточняется'
  if (slot) {
    const [y, m, d] = String(slot.day).split('-').map(Number)
    when = `${d} ${MONTHS[m - 1]} ${y}, ${String(slot.hour).padStart(2, '0')}:00`
  }

  const message = [
    '💖 Новая запись!', '',
    `👤 ${b.client_name}`,
    `📞 ${b.phone}`,
    b.vk_link ? `🔗 ${b.vk_link}` : null,
    `💅 ${b.service_title} — ${b.price_rub} ₽ (${b.duration_min} мин)`,
    `📅 ${when}`,
    Deno.env.get('ADMIN_URL') ? `\nПанель: ${Deno.env.get('ADMIN_URL')}` : null,
  ].filter(Boolean).join('\n')

  // random_id обязан помещаться в int32 (требование VK API)
  const params = new URLSearchParams({
    access_token: Deno.env.get('VK_TOKEN')!,
    v: '5.199',
    random_id: String(Date.now() % 2147483647),
    message,
  })
  const peerId = Deno.env.get('VK_PEER_ID')
  if (peerId) params.set('peer_id', peerId)
  else params.set('domain', Deno.env.get('VK_DOMAIN') ?? '')

  const res = await fetch('https://api.vk.com/method/messages.send', { method: 'POST', body: params })
  const json = await res.json()
  if (json.error) {
    console.error('VK error:', json.error) // 901 = мастер не разрешил сообщения сообществу
    return Response.json({ ok: false, vk_error: json.error })
  }
  return Response.json({ ok: true, message_id: json.response })
})
```

Параметры `messages.send` (ключ сообщества с правом `messages`, `peer_id`/`domain`, обязательный `random_id`) — по официальной документации метода [[6]].

**Деплой (без CLI, через дашборд):**
1. **Edge Functions → Deploy new function → Via Editor** → имя `notify-vk` → вставьте код → в настройках функции **выключите «Verify JWT»** → Deploy.
2. **Edge Functions → Secrets** добавьте: `VK_TOKEN`, `VK_DOMAIN` (или `VK_PEER_ID`), `WEBHOOK_SECRET` (придумайте длинную строку), `ADMIN_URL` = `https://USERNAME.github.io/lash-booking/#/admin`. (`SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` подставляются автоматически.)

Альтернатива через CLI: `npx supabase login` → `npx supabase link --project-ref ВАШ_REF` → `npx supabase secrets set VK_TOKEN=… VK_DOMAIN=… WEBHOOK_SECRET=…` → `npx supabase functions deploy notify-vk --no-verify-jwt`.

**Вебхук:**
1. **Database → Webhooks** (в новом интерфейсе — **Integrations → Webhooks**) → **Create a new hook**.
2. Name: `notify-vk-on-booking`; Table: `public.bookings`; Events: только **Insert**; Type: **Supabase Edge Functions** → `notify-vk`; Method: POST.
3. **HTTP Headers**: добавьте `x-webhook-secret` = значение вашего `WEBHOOK_SECRET`. Сохраните.

Вебхук пришлёт функции JSON вида `{ type: 'INSERT', table: 'bookings', record: {…} }` — именно его функция и разбирает [[11]].

**`src/lib/format.js`**

```js
// Даты, рубли, телефон. Чистые функции, без React.
import { TIMEZONE } from '../config'

export const MONTHS = ['Январь','Февраль','Март','Апрель','Май','Июнь','Июль','Август','Сентябрь','Октябрь','Ноябрь','Декабрь']
export const WEEKDAYS = ['Пн','Вт','Ср','Чт','Пт','Сб','Вс']

export const pad = (n) => String(n).padStart(2, '0')
export const dayStr = (y, m, d) => `${y}-${pad(m + 1)}-${pad(d)}` // m: 0–11

const tzParts = () => {
  const parts = new Intl.DateTimeFormat('ru-RU', {
    timeZone: TIMEZONE, year: 'numeric', month: '2-digit', day: '2-digit',
    hour: '2-digit', hourCycle: 'h23',
  }).formatToParts(new Date())
  const get = (t) => Number(parts.find((p) => p.type === t).value)
  return { y: get('year'), m: get('month') - 1, d: get('day'), h: get('hour') }
}
export const todayStr = () => { const { y, m, d } = tzParts(); return dayStr(y, m, d) }
export const nowHour = () => tzParts().h

export const parseDay = (s) => { const [y, m, d] = s.split('-').map(Number); return new Date(y, m - 1, d) }
export const shiftDay = (s, n) => { const t = parseDay(s); t.setDate(t.getDate() + n); return dayStr(t.getFullYear(), t.getMonth(), t.getDate()) }
export const monthRange = (month) => {
  const y = month.getFullYear(), m = month.getMonth()
  return { from: dayStr(y, m, 1), to: dayStr(y, m, new Date(y, m + 1, 0).getDate()) }
}
export const fmtDay = (s) =>
  new Intl.DateTimeFormat('ru-RU', { weekday: 'short', day: 'numeric', month: 'long' }).format(parseDay(s))
export const hourLabel = (h) => `${pad(h)}:00`
export const rub = (n) => `${new Intl.NumberFormat('ru-RU').format(n)} ₽`
export const duration = (min) =>
  min < 60 ? `${min} мин` : `${Math.floor(min / 60)} ч${min % 60 ? ` ${min % 60} мин` : ''}`

export const phoneDigits = (v) => v.replace(/\D/g, '')
export const fmtPhoneInput = (value) => {
  let d = phoneDigits(value)
  if (!d) return ''
  if (d[0] === '8') d = '7' + d.slice(1)
  if (d[0] !== '7') d = '7' + d
  d = d.slice(0, 11)
  let out = '+7'
  if (d.length > 1) out += ` (${d.slice(1, 4)}`
  if (d.length > 4) out += `) ${d.slice(4, 7)}`
  if (d.length > 7) out += `-${d.slice(7, 9)}`
  if (d.length > 9) out += `-${d.slice(9, 11)}`
  return out
}
export const vkHref = (link) => (/^https?:\/\//i.test(link) ? link : `https://${link}`)
```

```jsx
import { MONTHS, WEEKDAYS, dayStr } from '../lib/format'

// month — Date на 1-е число; marks — Set дат 'YYYY-MM-DD' со свободными слотами.
export default function Calendar({ month, setMonth, selected, marks, minDay, maxDay, onPick }) {
  const y = month.getFullYear(), m = month.getMonth()
  const offset = (new Date(y, m, 1).getDay() + 6) % 7 // неделя с понедельника
  const daysInMonth = new Date(y, m + 1, 0).getDate()
  const prevLast = new Date(y, m, 0)
  const canPrev = dayStr(prevLast.getFullYear(), prevLast.getMonth(), prevLast.getDate()) >= minDay
  const canNext = dayStr(y, m + 1 > 11 ? 0 : m + 1, 1) <= maxDay && new Date(y, m + 1, 1) <= new Date(maxDay)
  const move = (n) => setMonth(new Date(y, m + n, 1))

  return (
    <div className="rounded-3xl border border-rose-100 bg-white p-4 shadow-sm shadow-rose-100">
      <div className="mb-3 flex items-center justify-between">
        <button onClick={() => move(-1)} disabled={!canPrev} aria-label="Предыдущий месяц"
          className="h-10 w-10 rounded-xl text-2xl text-rose-400 disabled:text-stone-200">‹</button>
        <div className="font-display text-lg text-stone-800">{MONTHS[m]} {y}</div>
        <button onClick={() => move(1)} disabled={!canNext} aria-label="Следующий месяц"
          className="h-10 w-10 rounded-xl text-2xl text-rose-400 disabled:text-stone-200">›</button>
      </div>
      <div className="grid grid-cols-7 gap-1 text-center">
        {WEEKDAYS.map((w) => <div key={w} className="py-1 text-xs font-bold text-stone-300">{w}</div>)}
        {Array.from({ length: offset }).map((_, i) => <div key={`b${i}`} />)}
        {Array.from({ length: daysInMonth }).map((_, i) => {
          const d = i + 1, ds = dayStr(y, m, d)
          const disabled = ds < minDay || ds > maxDay
          const has = marks.has(ds), sel = ds === selected
          return (
            <button
              key={ds} disabled={disabled} onClick={() => onPick(ds)}
              className={`relative h-11 rounded-xl text-sm font-semibold transition active:scale-95 ${
                sel ? 'bg-rose-400 text-white shadow-md shadow-rose-200'
                : disabled ? 'text-stone-200'
                : has ? 'border border-rose-200 bg-rose-50 text-stone-700'
                : 'text-stone-400'}`}
            >
              {d}
              {has && !sel && <span className="absolute bottom-1 left-1/2 h-1 w-1 -translate-x-1/2 rounded-full bg-rose-400" />}
            </button>
          )
        })}
      </div>
      <p className="mt-3 text-center text-xs text-stone-300">Дни с точкой — есть свободные окошки</p>

  )
```

```jsx
import { useEffect, useMemo, useRef, useState } from 'react'
import { MASTER, BOOKING_DAYS_AHEAD } from '../config'
import { listServices, listSlotsRange, bookSlot, humanError } from '../lib/api'
import { todayStr, nowHour, shiftDay, parseDay, monthRange, fmtDay, hourLabel, rub } from '../lib/format'
import Header from '../components/Header'
import ServicePicker from '../components/ServicePicker'
import Calendar from '../components/Calendar'
import SlotPicker from '../components/SlotPicker'
import BookingForm from '../components/BookingForm'

import { SectionTitle, Spinner, Err } from '../components/ui'

export default function ClientPage() {
  const today = todayStr()
  const maxDay = shiftDay(today, BOOKING_DAYS_AHEAD)
  const [services, setServices] = useState(null)
  const [loadErr, setLoadErr] = useState('')
  const [month, setMonth] = useState(() => { const t = parseDay(today); return new Date(t.getFullYear(), t.getMonth(), 1) })
  const [slots, setSlots] = useState([])
  const [reload, setReload] = useState(0)
  const [service, setService] = useState(null)
  const [day, setDay] = useState(null)
  const [slot, setSlot] = useState(null)
  const [busy, setBusy] = useState(false)
  const [bookErr, setBookErr] = useState('')
  const [done, setDone] = useState(null)
  const calRef = useRef(null), formRef = useRef(null)

  useEffect(() => {
    listServices().then((s) => setServices(s.filter((x) => x.is_active))).catch((e) => setLoadErr(humanError(e)))
  }, [])

  useEffect(() => {
    const { from, to } = monthRange(month)
    listSlotsRange(from, to).then(setSlots).catch(() => setSlots([]))
  }, [month, reload])

  // Свободные слоты по дням; сегодняшние прошедшие часы скрываем
  const freeByDay = useMemo(() => {
    const map = new Map()
    for (const s of slots) {
      if (s.status !== 'free') continue
      if (s.day < today || (s.day === today && s.hour <= nowHour())) continue
      if (!map.has(s.day)) map.set(s.day, [])
      map.get(s.day).push(s)
    }
    return map
  }, [slots, today])

  const scrollTo = (ref) => setTimeout(() => ref.current?.scrollIntoView({ behavior: 'smooth', block: 'start' }), 50)
  const pickService = (s) => { setService(s); scrollTo(calRef) }
  const pickDay = (ds) => { setDay(ds); setSlot(null) }
  const pickSlot = (s) => { setSlot(s); setBookErr(''); scrollTo(formRef) }

  const submit = async (values) => {
    setBusy(true); setBookErr('')
    try {
      const res = await bookSlot({ slotId: slot.id, serviceId: service.id, ...values })
      setDone(res); window.scrollTo(0, 0)
    } catch (e) {
      setBookErr(humanError(e))
      if ((e.message || '').includes('SLOT_TAKEN')) { setSlot(null); setReload((k) => k + 1) }
    } finally { setBusy(false) }
  }

  const reset = () => {
    setDone(null); setService(null); setDay(null); setSlot(null)
    setReload((k) => k + 1); window.scrollTo(0, 0)
  }

  if (done) return <div className="mx-auto max-w-md px-4 pb-16"><Success booking={done} onReset={reset} /></div>

  return (
    <div className="mx-auto max-w-md px-4 pb-16">
      <Header />
      <Err>{loadErr}</Err>
      <section className="mt-2">
        <SectionTitle step="1">Выберите услугу</SectionTitle>
        {services === null
          ? <div className="flex justify-center py-8 text-rose-300"><Spinner /></div>
          : <ServicePicker services={services} selectedId={service?.id} onSelect={pickService} />}
      </section>

      {service && (
        <section ref={calRef} className="mt-8 scroll-mt-4">
          <SectionTitle step="2">Дата и время</SectionTitle>
          <Calendar month={month} setMonth={setMonth} selected={day}
            marks={new Set(freeByDay.keys())} minDay={today} maxDay={maxDay} onPick={pickDay} />
          {day && (
            <div className="mt-4">
              <p className="mb-2 text-sm font-bold capitalize text-stone-500">{fmtDay(day)}</p>
              <SlotPicker slots={freeByDay.get(day) || []} selectedId={slot?.id} onSelect={pickSlot} />
            </div>
          )}
        </section>
      )}

      {slot && service && (
        <section ref={formRef} className="mt-8 scroll-mt-4">
          <SectionTitle step="3">Ваши контакты</SectionTitle>
          <BookingForm
            summary={`${service.title} · ${fmtDay(day)}, ${hourLabel(slot.hour)} · ${rub(service.price_rub)}`}
            busy={busy} error={bookErr} onSubmit={submit}
          />
        </section>
      )}

      <footer className="mt-12 text-center text-xs text-stone-300">
        {MASTER.name} · запись открыта на {BOOKING_DAYS_AHEAD} дней вперёд
      </footer>
    </div>
  )
}
```

```jsx
    return () => subscription.unsubscribe()
  }, [])

  if (!isConfigured) return <div className="mx-auto max-w-md p-6"><Err>Supabase не настроен: заполните ключи.</Err></div>
  if (session === undefined) return <div className="flex justify-center pt-24 text-rose-300"><Spinner /></div>
  if (!session) return <Login />

  return (
    <div className="mx-auto max-w-md px-4 pb-28 pt-6">
      <div className="mb-5 flex items-center justify-between">
        <h1 className="font-display text-2xl text-stone-800">Панель мастера</h1>
        <button onClick={signOutAdmin} className="rounded-xl px-3 py-2 text-sm font-bold text-stone-400">Выйти</button>
      </div>
      {tab === 'bookings' && <BookingsTab />}
      {tab === 'slots' && <SlotsTab />}
      {tab === 'services' && <ServicesTab />}

      <nav className="fixed inset-x-0 bottom-0 border-t border-rose-100 bg-white/95 pb-[env(safe-area-inset-bottom)] backdrop-blur">
        <div className="mx-auto grid max-w-md grid-cols-3">
          {TABS.map((t) => (
            <button key={t.id} onClick={() => setTab(t.id)}
              className={`flex flex-col items-center gap-0.5 py-3 text-xs font-bold ${tab === t.id ? 'text-rose-500' : 'text-stone-400'}`}>
              <span className="text-2xl">{t.icon}</span>{t.label}
            </button>
          ))}
        </div>
      </nav>
```

```jsx
import { useEffect, useState } from 'react'
import { WORK_HOURS } from '../../config'
import { listSlotsRange, addSlot, removeSlot, humanError } from '../../lib/api'
import { todayStr, hourLabel } from '../../lib/format'
import { Spinner, Err } from '../../components/ui'

export default function SlotsTab() {
  const [day, setDay] = useState(todayStr())
  const [slots, setSlots] = useState(null)
  const [busyHour, setBusyHour] = useState(null)
  const [err, setErr] = useState('')
  const [reload, setReload] = useState(0)

  useEffect(() => {
    setSlots(null)
    listSlotsRange(day, day).then(setSlots).catch((e) => { setErr(humanError(e)); setSlots([]) })
  }, [day, reload])

  const byHour = new Map((slots || []).map((s) => [s.hour, s]))
  const tap = async (hour) => {
    const s = byHour.get(hour)
    if (s?.status === 'booked') return
    setBusyHour(hour); setErr('')
    try {
      if (s) await removeSlot(s.id)
      else await addSlot(day, hour)
      setReload((k) => k + 1)
    } catch (e) { setErr(humanError(e)) }
    finally { setBusyHour(null) }
  }

  const free = (slots || []).filter((s) => s.status === 'free').length
  const booked = (slots || []).filter((s) => s.status === 'booked').length

  return (
    <div>
      <input type="date" value={day} min={todayStr()}
        onChange={(e) => e.target.value && setDay(e.target.value)}
        className="w-full rounded-2xl border border-rose-200 bg-white px-4 py-3.5 text-lg font-bold text-stone-800 outline-none focus:border-rose-400" />
      {slots === null ? <div className="flex justify-center py-10 text-rose-300"><Spinner /></div> : (
        <>
          <p className="mt-3 text-sm font-bold text-stone-400">Свободно: {free} · Занято: {booked}</p>
          <div className="mt-3 grid grid-cols-3 gap-2">
            {WORK_HOURS.map((h) => {
              const s = byHour.get(h)
              const isBooked = s?.status === 'booked'
              const isFree = Boolean(s) && !isBooked
              return (
                <button key={h} disabled={isBooked || busyHour === h} onClick={() => tap(h)}
                  className={`rounded-2xl py-4 text-lg font-bold transition active:scale-95 disabled:active:scale-100 ${
                    isBooked ? 'bg-stone-100 text-stone-400'
                    : isFree ? 'bg-rose-400 text-white shadow-md shadow-rose-200'
                    : 'border-2 border-dashed border-rose-200 bg-white text-stone-400'}`}>
                  {isBooked ? '🔒 ' : isFree ? '✓ ' : '+ '}{hourLabel(h)}
                </button>
              )
            })}
          </div>
          <div className="mt-3"><Err>{err}</Err></div>
          <p className="mt-4 text-sm leading-relaxed text-stone-400">
            Тап по «+» — открыть окошко. Тап по розовому — закрыть его.
```

Free-проект Supabase засыпает после недели без запросов [[29]], поэтому добавляем «будильник» (запросы к БД считаются активностью):

```yaml
name: Keep Supabase awake
on:
  schedule:
    - cron: "0 6 * * 1,4"   # понедельник и четверг, 06:00 UTC
  workflow_dispatch:
jobs:
  ping:
    runs-on: ubuntu-latest
    steps:
      - name: Ping Supabase REST
        run: |
          curl -sf "${{ secrets.VITE_SUPABASE_URL }}/rest/v1/services?select=id&limit=1" \
            -H "apikey: ${{ secrets.VITE_SUPABASE_ANON_KEY }}"
```

**Запуск:**
1. Локально: `npm install` → появится `package-lock.json` (его **обязательно** коммитим — `npm ci` в workflow без него упадёт).
2. Проверка: скопируйте `.env.example` в `.env`, вставьте URL и anon-ключ из **Supabase → Project Settings → API**, затем `npm run dev`.
3. Создайте репозиторий `lash-booking`, запушьте весь проект в `main`.
4. GitHub → **Settings → Secrets and variables → Actions** → секреты `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
5. **Settings → Pages → Build and deployment → Source: GitHub Actions**. Пуш → вкладка Actions → через ~1–2 минуты сайт жив.
6. В ВК: **Управление сообществом → Меню / Кнопка действия** → ссылка «Онлайн-запись 💖» на сайт + закреплённый пост. Трафик из мобильного браузера ВК работает без нюансов — сайт полностью статический, без cookie-авторизации на клиентской части.

## Честные ограничения и чек-лист

- **Спам/злоупотребления:** anon-ключ публичный, и теоретически скрипт может занимать окошки. RPC валидирует имя/телефон, мастер отменяет фейки в один тап. Если появится спам — следующий шаг: бесплатная Yandex SmartCaptcha перед `book_slot`.
- **Не включайте регистрацию в Auth** и не кладите `service_role`/`VK_TOKEN` во фронтенд — они только в секретах Edge Function.
- **Пин-код** — минимум 6 цифр; Supabase сам ограничивает частоту попыток входа.
- **GitHub отключает cron-расписания** после ~60 дней без коммитов в репозитории — если сайт «замолчал», сделайте любой коммит или запустите keepalive вручную (workflow_dispatch).
- Часы — целые (`WORK_HOURS`), часовой пояс мастера — `TIMEZONE` в `config.js`; прошедшие сегодняшние часы клиенту не показываются.

**Финальный тест:** откройте сайт с телефона → запись → мастеру прилетает сообщение в ВК → в `/#/admin` запись видна → «Отменить» → окошко снова свободно на сайте. Если сообщение не пришло — смотрите логи Edge Function: ошибка `901` означает, что мастер ещё не написал сообществу первым [[6]].
